# typing-speed-test
simple website to test the typing speed of a user in wpm


FEATURES OT THE WEBPAGE
1--REAL TIME TYPING TEST 
2--WPM CALCULATION 
3--PROGRESS VISUALIZATION 
4--RESULT DISPLAY 

INTERACTIVE FEATURE 
1-- 3 DIFFICULTY LEVELS (EASY MEDIUM & HARD)
2-- TYPING SPEED COUNTER 
3--SOUND EFFECT 
4--DARK MODE 

PROGRESSIVE TRACKING 
1-- SCORE HISTORY ( USE LOCAL STORAGE TO STORE HISTORY OF UPTO LAST 10 RESULTS )
2-- TYPIN TIPS

  ----DARK MODE , SOUND EFFECT AND TIPS
